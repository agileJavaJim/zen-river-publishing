# Zen River Publishing

The Zen River Publishing hub — a single-page static site for the *Hours Back* series by Maya Bennett.

- `index.html` — the whole site (styles + newsletter script inline, no build step, no dependencies)
- Books link out to Amazon (`amazon.com/dp/<ASIN>`) — the ebooks are KDP Select exclusive, so they are never sold directly here
- Newsletter form posts via [FormSubmit](https://formsubmit.co) AJAX to `james.robinson12128@gmail.com` — **the address must click FormSubmit's one-time activation email before submissions arrive**

Published with GitHub Pages from the `main` branch.
